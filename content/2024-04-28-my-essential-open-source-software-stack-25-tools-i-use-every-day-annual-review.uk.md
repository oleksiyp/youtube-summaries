# Огляд Open Source програмного забезпечення

## Вступ

Щорічний огляд open source інструментів, які автор регулярно використовує. Відео охоплює безліч проєктів із короткими описами та посиланнями на докладні матеріали.

---

## Інструменти керування серверами

### Webmin
- **Призначення**: графічний інтерфейс для керування Linux-серверами
- **Переваги**:
  - Просте встановлення через стандартні репозиторії
  - Альтернатива командному рядку для адміністрування
  - Моніторинг CPU, пам'яті, дисків
  - Керування файловими системами, безпекою, логами
  - Можливість керування кількома серверами з єдиного інтерфейсу
- **Цільова аудиторія**: користувачі, що переходять із Windows Server або бажають мати GUI замість CLI

### Pi-KVM
- **Опис**: апаратно-програмне рішення на базі Raspberry Pi
- **Функції**: KVM-перемикач для віддаленого доступу до фізичних машин
- **Застосування**: ідеальний для MSP (Managed Service Providers) і віддаленого керування клієнтськими системами

---

## Мережеві інструменти та зворотні проксі

### Nginx Proxy Manager
- **Функції**: просте керування зворотними проксі-серверами
- **Можливості**:
  - Графічний інтерфейс для налаштування
  - Автоматичні SSL-сертифікати
  - Списки контролю доступу
  - Фільтрація за IP-адресами
  - Автентифікація для захищеного доступу

### NetBird
- **Тип**: VPN-рішення на базі WireGuard
- **Особливості**:
  - Просте налаштування VPN-з'єднань
  - Керування користувачами та групами
  - Гранульований контроль доступу до машин
  - Моніторинг стану підключень (онлайн/офлайн)
- **Застосування**: безпечні з'єднання для MSP і віддаленої роботи

---

## Інструменти віддаленого керування

### MeshCentral
- **Опис**: повноцінна RMM (Remote Monitoring and Management) система
- **Можливості**:
  - Віддалений робочий стіл через браузер
  - Доступ до термінала/командного рядка
  - Керування файлами (завантаження/вивантаження)
  - Детальне логування дій
  - Розширений набір інструментів адміністрування
- **Недолік**: поки немає підтримки Wayland
- **Плани**: буде використаний у серії «Створення MSP на Open Source»

### Remotely
- **Функції**: інструмент віддаленого робочого стола й підтримки
- **Особливості**:
  - Двофакторна автентифікація
  - Клієнти для Windows і Linux
  - Доступ за кодом через браузер
  - Не потребує реєстрації для кінцевих користувачів
- **Статус**: активно розвивається, компанія зберегла open source ліцензію

### Guacamole
- **Опис**: clientless віддалений робочий стіл через браузер
- **Підтримка протоколів**: RDP, VNC та інші
- **Можливості**:
  - Групування підключень
  - Доступ до локальних машин через єдиний інтерфейс
  - Повноекранний режим
  - Не потребує встановлення клієнтського ПЗ

## Контейнеризація та віртуалізація

### Portainer
- **Призначення**: GUI для керування Docker-контейнерами
- **Переваги**:
  - Візуальний огляд контейнерів та їхніх статусів
  - Керування контейнерами одним кліком
  - Перегляд логів
  - Доступ до shell контейнерів
- **Версії**: Community Edition (безкоштовна) і Business Edition

### LXD Console (з Incus)
- **Функції**: вебінтерфейс для керування LXD/Incus контейнерами
- **Можливості**:
  - Моніторинг ресурсів (CPU, пам'ять)
  - Керування контейнерами та віртуальними машинами
  - Перегляд IP-адрес і конфігурацій
  - Вбудована вебконсоль для доступу до контейнерів
  - Керування кількома серверами

---

## Безпека та автентифікація

### Vaultwarden
- **Опис**: легковісний форк Bitwarden на Rust
- **Функції**:
  - Менеджер паролів із шифруванням
  - Двофакторна автентифікація
  - Синхронізація з клієнтами Bitwarden
  - Інтеграція з браузерами
  - Сімейний доступ і спільне використання
- **Переваги**: менш ресурсомісткий, ніж оригінальний Bitwarden

### Authentik
- **Опис**: рішення для єдиного входу (SSO)
- **Підтримувані протоколи**: LDAP, SAML, OIDC
- **Застосування**:
  - Централізована автентифікація для всіх сервісів
  - Портал доступу до застосунків
  - Керування користувачами та правами доступу
- **Інтеграція**: використовується з MeshCentral, Nextcloud, Headscale, NetBird та іншими

## Аналітика та моніторинг

### Metabase
- **Призначення**: інструмент для створення дашбордів і звітів
- **Можливості**:
  - Візуалізація даних за допомогою графіків
  - Відстеження бізнес-метрик
  - Аналіз трендів
  - Інтуїтивний інтерфейс із мінімальним кодуванням
- **Приклад використання**: відстеження продажів на eBay, аналіз сезонності, облік витрат на доставку
- **Версії**: безкоштовна та професійні версії для бізнесу

---

## Хмарні сховища та колаборація

### Nextcloud
- **Опис**: повнофункціональна платформа для роботи з файлами й колаборації
- **Основні функції**:
  - Зберігання та синхронізація файлів
  - Календарі й контакти
  - Керування задачами (To-Do списки)
  - Розширюваність через застосунки
- **Налаштування**: Nextcloud All-in-One (AIO) для простого встановлення
- **Інтеграція**: працює з Authentik для SSO

## Комунікації

### Rocket.Chat
- **Призначення**: платформа для командного спілкування
- **Застосування**: спільнота для підписників каналу
- **Функції**:
  - Канали для обговорень
  - Підтримка SSO
  - Обмін файлами та посиланнями
  - Сповіщення про нові відео
- **Доступ**: discuss.opensourceisawesome.com

### Matrix (Dendrite)
- **Опис**: децентралізований месенджер
- **Застосування**: сімейний чат
- **Переваги**:
  - Приватні комунікації
  - Самостійний хостинг
  - Клієнти для desktop і mobile
  - Групові чати та особисті повідомлення

## Ведення нотаток і документації

### BookStack
- **Призначення**: організація документації та інструкцій
- **Структура**: Полиці → Книги → Розділи → Сторінки
- **Особливості**:
  - Потужний пошук
  - Покрокові інструкції для всіх відео
  - Інтеграція з Authentik
  - Підтримка Markdown

### Trilium Notes
- **Опис**: ієрархічний застосунок для нотаток
- **Функції**:
  - Швидкий пошук
  - Деревоподібна структура
  - Власний сервер синхронізації
  - Electron-клієнт для desktop
- **Застосування**: особисті списки (наприклад, список фільмів для сімейних переглядів)
- **Альтернатива**: Obsidian, Logseq, Joplin

## Контент-менеджмент

### WriteFreely
- **Призначення**: мінімалістична платформа для блогінгу
- **Особливості**:
  - Просте налаштування
  - Публічні або приватні блоги
  - Підтримка зображень
- **Приклад використання**: проєкт реставрації піаніно з фотощоденником

### Pixelfed (згаданий як Pixer)
- **Опис**: самостійний хостинг зображень
- **Функції**:
  - Завантаження та організація фото
  - Генерація URL для вставлення в пости
  - Інтеграція з блог-платформами
- **Застосування**: хостинг зображень для WriteFreely

## Домашня автоматизація

### Home Assistant
- **Опис**: потужна платформа домашньої автоматизації
- **Переваги**:
  - Повна локальна робота без хмари
  - Конфіденційність даних
  - Інтеграція з безліччю пристроїв
  - Автоматизації без необхідності писати код
- **Еволюція**: раніше потрібні були YAML-файли, тепер усе через GUI
- **Функції**:
  - Керування камерами
  - Дашборди для моніторингу
  - Складні сценарії автоматизації

## Створення контенту

### Shotcut
- **Призначення**: відеоредактор
- **Переваги над альтернативами**:
  - Швидкий та ефективний робочий процес
  - Інтуїтивна часова шкала
  - Система кліпів
  - Налаштовувані види й метри
  - Менша крива навчання, ніж у DaVinci Resolve чи Adobe
- **Розвиток**: постійні оновлення з новими функціями

### OBS (Open Broadcaster Software)
- **Призначення**: запис екрана та стримінг
- **Перевага**: підтримка Wayland
- **Причина переходу**: попередній інструмент (Simple Screen Recorder) не підтримує Wayland
- **Актуальність**: Wayland стає стандартом, X11 поступово відходить

---

## Dashy
- **Опис**: налаштовуваний дашборд для швидкого доступу до сервісів
- **Функції**:
  - Візуальна організація посилань на сервіси
  - Перевірка доступності сервісів (ping)
  - Візуальний редактор (не лише YAML)
  - Доступ до домашніх і хмарних сервісів
- **Перевага**: простота налаштування й використання

---

## Підсумкові рекомендації

**Загальні поради від автора:**
- Усі згадані інструменти мають докладні відеоінструкції
- Посилання на відео й документацію в описі
- Багато проєктів мають як безкоштовні, так і платні версії
- **Важливо підтримувати проєкти фінансово**, якщо вони використовуються в бізнесі
- Подяка розробникам допомагає проєктам розвиватися
- Open source не означає, що не потрібно платити — це інвестиція в майбутнє проєкту

**Майбутні плани:**
- Друга частина огляду з додатковими інструментами
- Серія «Створення MSP на Open Source» з використанням багатьох згаданих інструментів
- Оновлення відео в міру розвитку проєктів
